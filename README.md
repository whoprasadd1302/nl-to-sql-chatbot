# Multilingual AI Database Chatbot

An AI-powered chatbot that converts natural language queries into SQL and retrieves data from a database.

## Features

- Conversational AI
- Chat Memory
- Sidebar Chat History
- SQLite Database
- Ollama Integration
- Qwen/Mistral Support

## Technologies

- Python
- Flask
- SQLite
- Ollama
- HTML
- CSS
- JavaScript

## Future Work

- Multilingual Support
- Text-to-SQL
- PostgreSQL
- Voice Input
